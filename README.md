# 🏦 Bank Management System

A simple Bank Management System built using Python.

## Features

- Create Account
- Customer Login
- View Balance
- Deposit Money
- Withdraw Money
- Admin Login
- View All Accounts
- Search Account
- Delete Account
- Total Number of Accounts

## Technologies Used

- Python
- Dictionary
- Loops
- Functions (if added later)
- Conditional Statements

## How to Run

1. Clone the repository.
2. Open terminal.
3. Run:

```bash
python bank_management.py
```
