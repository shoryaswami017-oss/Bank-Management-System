# 🏦 Bank Management System

A command-line Bank Management System built with Python.

This project simulates basic banking operations such as account creation, customer login, deposits, withdrawals, balance checking, and administrative account management.

## ✨ Features

### 👤 Customer

- Create a new bank account
- Login using account number
- View account balance
- Deposit money
- Withdraw money
- Check for insufficient balance
- Exit customer menu

### 🔐 Admin

- Admin password authentication
- View all accounts
- Search for an account
- Delete an account
- View total number of accounts
- Limited password attempts

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Functions
- Conditional Statements
- User Input
- Basic Authentication Logic
